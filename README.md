# WindHawk Mod - Minecraft Hotbar

Neste repositório estão as modificações apresentadas no canal @BitRizeBR (YouTube), desenvolvidas com o auxílio do Claude.ai.

---

## Sobre o Projeto

Este repositório contém o código atualizado e modificado a partir do mod oficial criado por m417z, autor do Windows 11 Taskbar Styler.

### O que este repositório faz

Foram feitas alterações no mod original, especificamente no estilo "Minecraft Hotbar", adaptadas para o Windows 11. O mod reorganiza e separa os elementos da barra de tarefas do Windows.

## Alterações Realizadas

- Posição da barra de tarefas.
- Separação dos ícones de atalho e das configurações do sistema (como data/hora e layout de teclado).

---

## Requisito Importante

Este mod funciona em conjunto com outro repositório do mesmo projeto:

- **[WindHawk--Mod--HideWindowsButton](https://github.com/BRUser1032/WindHawk--Mod--HideWindowsButton)** (responsável por ocultar o botão Iniciar).
